# 월간 일정표

자립지원센터의 월간 「일자리 근무 일정표 및 수업계획표」를 한 번만 만들고,
참여자별 계획표를 한 번에 인쇄하는 웹앱입니다.

## 진행 단계

1. **달력 화면 (지금)** — `public/` 정적 파일만. 데이터는 메모리에 있는 9월 예시이고 새로고침하면 사라집니다.
2. 저장 — Cloudflare Worker + D1, 1초 뒤 자동 저장, 비밀번호
3. 참여자 화면 · 개인별 인쇄
4. 공휴일 API (공공데이터포털 특일 정보) + 기관 자체 휴무일

## 써 보기

빌드 과정이 없습니다. `public/index.html`을 브라우저로 열거나:

```sh
cd public && python3 -m http.server 8000
```

## 꼬리표 규칙

- 줄 맨 앞에 `[탁구]`를 쓰면 `탁구` 꼬리표를 가진 사람의 계획표에만 들어갑니다. 꼬리표가 없는 줄은 모두에게 들어갑니다.
- `[1부][2부]`처럼 같은 묶음의 꼬리표를 여러 개 쓰면 그중 하나만 맞아도 들어갑니다.
- 어떤 묶음(예: 남/여)의 꼬리표가 하나도 없는 사람은 그 묶음의 줄을 모두 받습니다.
- 묶음은 `public/app.js` 맨 위의 `TAG_GROUPS` 상수에서 바꿉니다.
- `*`, `→`로 시작하면 파란색, `!`로 시작하면 빨간색입니다. 인쇄할 때 꼬리표와 `!`는 지워집니다.

참여자 실명은 저장소에 커밋하지 않습니다. 배포 후 참여자 화면에서 입력합니다.
